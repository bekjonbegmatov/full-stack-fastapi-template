# Monitoring node agent

1. Скопируйте `.env.example` в `.env`.
2. Вставьте URL главного сервера и токен агента из админки.
3. Запустите: `docker compose up -d --build`.

Агенту нужен только исходящий доступ к главному серверу по HTTPS. Входящие порты не нужны: порт `8080` опубликован только на localhost для health-check.
